# Datestamp (Android)

แอปประทับวันที่ถ่ายลงบนรูป อ่านวันที่จาก EXIF ของรูป แล้วบันทึกรูปใหม่ลงอัลบั้ม `Pictures/Datestamp` ไฟล์ต้นฉบับไม่ถูกแก้ไข ใช้ได้กับ Android 10 ขึ้นไป แอปไม่ขอสิทธิ์ใดๆ และไม่ใช้อินเทอร์เน็ต

## วิธีใช้แอป

1. เปิดแอป กด **เลือกรูป** (เลือกได้หลายรูป) หรือเลือกรูปในแกลเลอรีแล้วกด แชร์ > Datestamp
2. กด **บันทึก** รูปที่ประทับวันที่แล้วทุกรูปจะอยู่ในอัลบั้ม Datestamp

ค่าเริ่มต้น: วัน/เดือน/พ.ศ. สีเหลือง มุมล่างขวา ปรับได้ในหน้าแอป และแอปจำค่าที่ตั้งไว้

## วิธีสร้างไฟล์ติดตั้ง (APK) ด้วย GitHub

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main` รวมถึงโฟลเดอร์ `.github`
3. GitHub จะสร้างแอปให้อัตโนมัติ ดูความคืบหน้าได้ที่แท็บ **Actions** ใช้เวลาประมาณ 3-5 นาที
4. เมื่อเสร็จ ไปที่หน้า **Releases** ของ repository แล้วดาวน์โหลด `datestamp.apk`
5. เปิดไฟล์บนมือถือ Android แล้วอนุญาตให้ติดตั้งแอปจากแหล่งนี้

ทุกครั้งที่แก้โค้ดแล้ว push ขึ้น `main` จะได้ APK รุ่นใหม่ใน Releases

## หมายเหตุ

- APK แต่ละรุ่นถูกเซ็นด้วยกุญแจชั่วคราว เวลาอัปเดตต้องถอนการติดตั้งรุ่นเดิมก่อน แล้วค่อยติดตั้งรุ่นใหม่
- รูปที่ไม่มีวันที่ถ่ายใน EXIF จะใช้วันที่ของไฟล์แทน ถ้าหาวันที่ไม่ได้เลย รูปนั้นจะถูกข้าม
